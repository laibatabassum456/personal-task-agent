 # 🤖 AI Personal Task Agent

An AI-powered task management assistant that allows users to create and manage tasks using natural language.

## Features

- Natural language task creation
- AI reasoning loop
- Task prioritization
- Tool-based task execution
- Task logging
- Secure API key management

## Tech Stack

- Python
- Streamlit
- Groq LLM
- JSON storage
- Agent architecture
